# 阿纸个人简历

基于 Next.js、React 和 vinext 构建的个人简历网站。

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

页面代码位于 `app/` 目录。

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the vinext build output
